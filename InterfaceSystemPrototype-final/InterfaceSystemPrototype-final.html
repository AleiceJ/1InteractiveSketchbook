My navigation model is consistent across all pages, using a top navigation bar on desktop and a hamburger menu on mobile. This creates a system where users can move between sections without having to relearn the interface, or go through loops to know the status. The hierarchy is established through type (h1–h4) which are different from mobile to desktop. Spatial grouping, like title pages, filters, and content blocks are clearly separated which also contribute to the hierarchy of my interface. I approached the layout mobile-first, which led to vertically stacked content and simplified navigation. This decision reduces complexity and ensures that all interactions are accessible within a smaller screen before scaling up to desktop. Using Norman’s framework, I focused on affordances and signifiers through the use of clearly defined buttons, and navigation systems. For example, the rounded rectangles on the home page of the mobile version suggest clickable areas, while underlined navigation items indicate the current page. Feedback is present through state changes like filters, which helps reduce confusion by showing users what content is currently active. Mapping is used in the relationship between navigation and content, where each category directly corresponds to a page or filtered view. Constraints are intentionally applied by limiting navigation options and organizing content into fixed grids or lists, preventing users from becoming overwhelmed. Nielsen’s heuristics were also applied to strengthen usability of the interface. First, I used consistency and standards by repeating layout patterns, navigation placement, and typography across all page types. Second, I focused on visibility of system status through active states in navigation and filters, allowing users to understand where they are within the system. Third, I applied recognition rather than recall by keeping navigation visible and labeling all sections clearly, so users do not need to remember where content is located. The hamburger menu also supports this by providing access to all sections at any time. Shneiderman’s Golden Rules further informed my design decisions. I intentionally maintained consistency across page types, ensuring that users experience the same structure whether they are viewing sketches or micro-projects. I reduced short-term memory load by keeping navigation visible and organizing content into predictable patterns. I also aimed to keep users in control by allowing direct navigation through both top navigation and mobile menus. Structurally, the system is designed to prioritize clarity and organization. The use of grayscale allows me to focus on hierarchy, spacing, and interaction without distraction. The grid-based layout on desktop and linear layout on mobile ensure that content is readable and logically ordered. One constraint I worked within was maintaining a balance between quantity and simplicity: limiting the number of navigation options and standardizing content modules, I created a system that is easy to understand but still scalable from mobile to desktop. I believe my interface demonstrates structural coherence through consistent navigation, clear hierarchy, and intentional use of interaction patterns.
