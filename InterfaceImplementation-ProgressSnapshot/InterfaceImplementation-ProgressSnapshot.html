Translation Challenges

The biggest challenge in translation was realizing that what the plugin generated is not a direct use of what CSS can do, so I had to change a lot of the code and try to understand the code Figma is using and translate that into the code VS code uses. I expected that at least Figma would have the correct positioning so that I could easily just fix font in hierarchy, but it did not. At first when going through each line of code a lot of the words were stacking on top of each other. I learned that Figma uses absolute positioning which doesn't really translate well into VS code. I also was surprised that I had to work with HTML and CSS kind of simultaneously when writing the code for this. I assumed that it would be more similar to working with JS where I only had to write the base code in HTML and link those together and everything would then be in JS but that's not the case when working with CSS. it adds another layer of coding which I feel like takes a longer time and is more confusing to me. I’m having a hard time relating the two and writing code in CSS that can translate to HTML so that it shows up. Moving forward I will try to include the boxes so that I have the overall layout and work on fixing the position of the words that are stacked on each other.
